# 侧栏职责（#56）

`sidebar-state.js` 的 `deriveSidebarState(state, selection, previous)` 不访问 DOM、不发送消息。它推导有效选择、语言要求、字幕候选、按钮文案/操作能力，以及按媒体、语言、生成模式隔离的预检 key 和匹配结果。可用性复用 #55 的 `operationCapabilities`。

`sidebar-render.js` 集中 DOM 引用、语言候选与选项更新。选项内容的 key 不变时保留原节点，值相同也不重复写入，避免 2.5 秒刷新打断自定义下拉与键盘焦点。侧栏入口保留原有 DOM 布局与文案，负责调度渲染和用户事件。

`sidebar-preflight.js` 负责消息副作用；渲染预检状态本身不发送请求。成功缓存覆盖当前及之前的生成配置，显式刷新发送 force，错误结果不会变成成功缓存。结果只在完整 key 匹配时参与当前按钮状态。

回归覆盖无音轨、单语、已有字幕翻译、操作冲突、当前选择保留、媒体切换、预检缓存、强制重查，以及相同状态刷新保留 option 对象。浏览器和原生验证结果单独记录，fixture 不代表原生 IINA 已验收。

回退只需撤销该 PR，保留 #55；新模块均在 `sidebar.html` 和打包清单中，无数据迁移。
