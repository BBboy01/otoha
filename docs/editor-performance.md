# 编辑器基准（#54）

运行环境：2026-11-23，macOS arm64，Node VM fixture。自编 5,000 条双语字幕，每轮 50 次输入、50 次无正文变化的状态渲染与滚动，最后触发一次草稿计时器。7 轮取中位数，包含 fixture、排除浏览器 DOM 布局和真实 bridge/helper I/O。

| 指标                    | 基线 `20af0d7` |   优化后 |
| ----------------------- | -------------: | -------: |
| 50 次输入总耗时         |      395.76 ms | 82.21 ms |
| 50 次渲染与滚动总耗时   |      392.97 ms |  0.08 ms |
| 防抖回调耗时            |        0.02 ms |  1.54 ms |
| 整数组序列化累计 cue 数 |      4,500,000 |  505,000 |

快照成本移至计时器触发时；旧回调耗时低是因为深拷贝已在每次调度时完成。这是 Node CPU 微基准，不能作为 IINA 输入延迟或布局性能结论。dirty 比较仍为每次正文变化 O(n)，没有重写正文状态或文件格式。

复现：`node scripts/benchmark-subtitle-editor.cjs 20af0d7` 与 `node scripts/benchmark-subtitle-editor.cjs`。计时会随机器负载变化。

回归覆盖重复渲染、最新位置/正文、撤销至基线、待确认草稿、快速关闭缓存、新 session 防抖取消、revision 变化和保存失败。回退本 PR 可恢复旧调度与比较，无需迁移。
