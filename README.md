# Otoha

Otoha is a planned macOS plugin for IINA that transcribes a video's audio locally, translates it, and generates a bilingual SRT subtitle file. It is designed to use Apple's on-device speech and translation capabilities together with FFmpeg installed on the Mac.

The project is currently at the planning stage. See the [V1 proposal](docs/iina-transcription-translation-plugin-plan.md) for the agreed scope, architecture, UI flow, and prototype checks.
